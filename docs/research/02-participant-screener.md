## Eligibility gate

All six conditions must pass. A successful specialist-tool workflow remains eligible.

| Condition | Pass | Evidence |
|---|---:|---|
| Intermediate/advanced behavior with authentic content | ☐ | |
| Self-directed resource or practice choices | ☐ | |
| Two or more materially different resources in last 30 days | ☐ | |
| Concrete authentic-content example in last 30 days | ☐ | |
| Recent recognition-to-production gap, recurring corrected mistake, or both | ☐ | |
| Recent non-sensitive artifact or tool path can be shown | ☐ | |
