## Counting rules

- A handoff occurs when an item, its context, or the learner’s intention crosses between tools, people, devices, screens with separate data models, or physical and digital media. Moving between two screens in one tool counts only if the participant must manually reconstruct context or intent.
- Manual transfer: each copy, retype, import, export, screenshot, or physical transcription.
- Duplicate: substantially the same information re-entered because systems do not share it; intentional learning reformulation is not duplication.
- Lost context: evidence shows it existed before the handoff and is unavailable after. Otherwise use “not captured” or “unavailable.”
- Keep estimated historical time separate from recorded task time. Do not create a composite friction score.
